Инструмент для восстановления подключения Discord в условиях сетевых ограничений.

---

## 📌 Краткое описание
Вспомогательное приложение, предназначенное для запуска Discord при проблемах с подключением, вызванных сетевыми ограничениями или нестабильным соединением.

---

## 📖 Описание
Данный проект разработан для пользователей, которые сталкиваются с невозможностью подключения к Discord из-за блокировок, ограничений провайдера или нестандартных сетевых условий.

Инструмент работает **в связке с уже запущенным Discord** и требует соблюдения корректной последовательности запуска. Программа не модифицирует файлы Discord и не вмешивается в его внутренние процессы.

Проект предназначен исключительно для личного использования и ознакомительных целей.

---

## ▶️ Порядок запуска
⚠️ **Критически важно соблюдать порядок**

1. Запустите **`discord.exe`**
2. После этого запустите данный инструмент
3. Вернитесь в Discord и дождитесь соединения

❗ Запуск инструмента **до Discord** может привести к некорректной работе.

---

## 🛡️ Антивирус и защита
В некоторых случаях антивирусное ПО или Защитник Windows могут:
- блокировать запуск программы
- удалять файл при скачивании
- мешать корректной работе

### Рекомендации:
- Временно отключить антивирус  
  **или**
- Добавить папку с программой в исключения

Это стандартная ситуация для сетевых инструментов и не является признаком вредоносного кода.

---

## ⚙️ Требования
- Windows 10 / 11
- Установленный Discord (Desktop версия)
- Права на запуск сторонних приложений
